# Array Implementation in Python

A simple implementation and exploration of arrays using Python.

## 📌 About

This repository contains basic array operations and concepts implemented in Python.

The goal is to understand how arrays work, how elements are accessed, and the time complexity of common operations.

## 🧠 Concepts Covered

- Array creation
- Accessing elements
- Updating elements
- Traversing an array
- Inserting elements
- Deleting elements
- Searching
- Iterating through arrays
- Time and space complexity

## 🛠️ Technologies Used

- Python 3
